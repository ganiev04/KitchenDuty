# KitchenDuty — дежурства на кухне

Локальное iOS-приложение на SwiftUI: личные кабинеты, расписание на неделю и оценки других дежурных. База SwiftData хранится на устройстве, интернет не нужен.

## Как запустить

1. Откройте `KitchenDuty.xcodeproj` в Xcode.
2. Выберите симулятор iPhone или свой iPhone.
3. Нажмите Run (⌘R).

## Готовые аккаунты

На экране входа можно нажать карточку — логин и пароль подставятся сами.

| Имя | Логин | Пароль | Роль |
|---|---|---|---|
| Анна | `anna` | `anna123` | дежурный |
| Иван | `ivan` | `ivan123` | дежурный |
| Мария | `maria` | `maria123` | дежурный |
| Олег | `oleg` | `oleg123` | админ (может менять расписание) |

Новый кабинет создаётся вкладкой **Регистрация**.

## Что умеет приложение

- вход и регистрация без падений: пустые поля и неверный пароль показывают текст ошибки;
- расписание на 7 дней, переключение недель;
- оценки 1–5 звёзд с комментарием (один раз на человека за текущую неделю, можно обновить);
- личный кабинет: свои дежурства, средняя оценка, смена имени и пароля.

Данные не синхронизируются между разными телефонами: у каждого устройства своя локальная база.
